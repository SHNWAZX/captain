## ✨ Highlights

- ⚡ **Fast** — Edge-deployed, lazy-loaded media, prefetched routes
- 🎨 **Polished** — Motion micro-interactions, blur reveals, liquid glass
- 📱 **Responsive** — Pixel-perfect from 320px to 4K
- 🔒 **Secure** — Strict TS, copy-guard, no leaked keys
- 🧱 **Modular** — File-based routing, semantic design tokens

## 🛠 Stack

| Layer        | Tech                                        |
| ------------ | ------------------------------------------- |
| Framework    | TanStack Start v1 + React 19                |
| Build        | Vite 7                                      |
| Styling      | Tailwind CSS v4 + custom design tokens      |
| Animation    | Motion (Framer)                             |
| Icons        | Lucide                                      |
| Deployment   | Cloudflare Workers                          |

## 🚀 Quick start

```bash
bun install
bun run dev
```

Open [http://localhost:5173](http://localhost:5173).

```bash
bun run build      # production build
bun run preview    # preview the build
```

## 📁 Structure

```text
src/
├─ assets/         # images, video, fonts
├─ components/     # Portfolio, Hero, Services, Skills, Contact…
├─ routes/         # file-based routes (TanStack Router)
├─ styles.css      # design tokens (oklch) + Tailwind layer
└─ router.tsx      # router bootstrap
```
